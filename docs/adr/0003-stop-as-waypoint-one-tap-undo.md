# 선택 정차 지점은 경유지로 즉시 추가하고, 주행 중에는 한 번 탭 + 취소 유예

정차 지점을 목적지로 바꾸면 원래 목적지가 사라지므로 `NaviHelper.addWaypoint`로 경유지 1개를 추가하고 원 목적지는 유지한다. 경유지가 이미 2개(SDK 최대치)면 어느 것을 교체할지 사용자에게 묻는다. 정차 후에 확인하면 이미 원래 경로로 지나간 뒤라 쓸모가 없으므로, 일반 내비 앱의 추천 경로 선택처럼 주행 중 선택도 즉시 반영한다. 주행 중에는 후보 최대 2개를 큰 카드로만 보여 주고 한 번 탭하면 바로 `addWaypoint`, 이후 10초간 "취소" 버튼을 띄워 누르면 `removeWaypoint`로 되돌린다.

## Considered Options

- 운전자 음성 "확인" 후 전달: Pleos STT가 "준비 중"이라 쓸 수 없다(`docs/research/pleos-myproject.md`).
- 정차 후 화면 확인 후 전달: 이미 원래 경로로 지나간 뒤라 기각.

## Consequences

- 주행 중 상호작용 규칙(PL-UJFQXQ)은 "음성과 확인·취소만"에서 "음성과 한 번 탭 선택·취소"로 바뀐다. 비교 화면·펼치기·스크롤은 주행 중 계속 막는다.
- 화면 탭으로는 운전자와 동승자를 구분할 수 없어 누가 눌러도 같게 반영된다.
- 주행 중 화면은 AAOS `distractionOptimized` Activity여야 한다.
- 취소 유예 10초는 시연하며 조정한다.
- `addWaypoint` 후 원 목적지가 유지되는지는 에뮬레이터 실측으로 확정한다(#1).
