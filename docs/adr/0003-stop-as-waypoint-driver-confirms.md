# 선택 정차 지점은 경유지로 추가하고, 운전자 음성 확인 후 전달

정차 지점을 목적지로 바꾸면 원래 목적지가 사라지므로 `NaviHelper.addWaypoint`로 경유지 1개를 추가하고 원 목적지는 유지한다. 경유지가 이미 2개(SDK 최대치)면 어느 것을 교체할지 사용자에게 묻는다. SDK에 경로 변경 확인 UI가 없으므로 앱이 직접 확인 단계를 두며, 동승자가 후보를 골라도 운전자가 음성으로 "확인"한 뒤에만 전달한다.

## Consequences

- `addWaypoint` 후 원 목적지가 유지되는지는 문서에 명시가 없어 에뮬레이터 실측으로 확정한다.
