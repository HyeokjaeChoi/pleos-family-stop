# 음성은 시연 범위에 포함하고 ON_DEVICE 모드로 고정

시연 범위에 '음성 선택'이 있으므로 음성 요청(STT)·결과 안내(TTS)를 보류(L/blocked)에서 시연 대상(M)으로 올리되, 범위를 '음성 후보 선택 확정'과 '1~2문장 결과 안내'로 좁힌다. STT/TTS 기본값은 HYBRID(서버 우선)지만 서버 모드의 음성 외부 전송·보존 조건을 확인하지 못했으므로 `ON_DEVICE`로 고정해 음성이 차량 밖으로 나가지 않게 한다. 그래서 '매 요청 외부 전송 동의' 대신 '온디바이스 처리 고지 1회'만 둔다.

## Consequences

- 주행 중 후보는 최대 2개를 번호로 읽고, "다음" 요청 시 3번째를 안내한다(1~2문장 규칙·주의 분산).
- TTS `onError` 시 같은 문장을 자동 재시도하지 않고 화면에 한 줄 상태(예: "후보 2개 · 정차 후 확인")만 띄운 뒤 상세는 정차 후에 보여준다.
- 온디바이스 엔진 오류 시 정차 후 화면 입력으로 대체한다.
- 지표 수집(정차 가치·재사용)은 시연 범위 밖으로 보류(PT 이후)한다.
