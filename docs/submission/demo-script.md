# 시연 영상 시나리오 (제출본)

제출 메일에 첨부한 `FamilyStop_demo.mp4`의 장면 구성이다. 길이 2분 11초, 1920×1080 30fps, H.264/AAC, 자막과 한국어 내레이션이 들어 있다. Pleos Connect 에뮬레이터 화면만 담았고, 개발자 실명이나 계정 정보는 나오지 않는다.

## 녹화 방법

- 앱: debug 빌드로 찍었다. 앱 코드는 `apk/`의 release APK와 같다(마지막 앱 코드 변경은 #82).
- 사전 상태: 내비에서 더현대서울 안내를 시작해 두고, `scripts/vconsole.sh`로 `gear P`·`soc 35`·`range 180`·`charge off`를 맞췄다. 위치 권한은 장면 7 전까지 허용 상태다.
- 장면 1~4: `adb shell screenrecord --size 1920x1080 --bit-rate 8000000`으로 녹화했다. AAOS 에뮬레이터에서도 동작한다.
- 장면 5~7: 같은 날 같은 빌드에서 찍은 전체 해상도 스크린숏을 한 장에 2.5~7초씩 이었다. 호스트 부하로 에뮬레이터가 자주 멈춰서 연속 녹화본을 쓸 수 없었다. 화면은 실제 앱 화면이지만 움직임은 없다.
- 차량 값 변경: 장면 5는 `gear D`·`speed 60`, 장면 6은 `charge on` → `soc 60`·`range 300` → `soc 80`·`range 400` → `charge off`.
- 내레이션은 macOS `say -v Yuna`로 만들었다. 자막과 카드는 PNG로 만들어 ffmpeg로 겹쳤다.

## 다시 녹화할 때

- 장면 5는 ADR-0003 규칙(주행 중 비교·펼치기·스크롤 불가)을 그대로 보여 준다.
- 에뮬레이터 내비의 경로 시간·거리는 고정값에 가까워서 장면 3의 도착 지연은 실제 값이 아니다. 그래서 자막에 "시연 데이터"를 표시했다(ADR-0001: 가상 데이터는 시연 한정).
- 경유지를 추가하면 5–9초 재탐색하는 동안 목적지가 비어 보인다(`docs/agents/emulator.md` §6). `onWaypointChanged` 이후 상태로 찍는다.
- 10초 취소 카운트다운이 떠 있는 동안에는 `uiautomator dump`가 멈춘다. 이때는 고정 좌표로 탭한다.
- 호스트 부하가 높으면 에뮬레이터가 멈추거나 `car_service` 연결이 끊긴다. 부하를 줄이고 콜드 부팅한 뒤 녹화한다.
