# 시연 영상 시나리오 (초안)

목표 2–3분. 목업·프로토타입·화면녹화 인정 (공식 FAQ). 에뮬레이터 화면녹화 기준. #14(통합) 완료 후 녹화한다. 영상·링크에 개발자 실명, 계정 정보가 보이면 안 된다.

## 사전 준비

- 에뮬레이터 부팅, release APK 설치 ([release-apk.md](release-apk.md)).
- 위치: `adb emu geo fix 127.0276 37.4979`. 시연 구간 시설 데이터가 있는 좌표인지 `:feature:recommend` 데이터 확인.
- 차량 값: `scripts/vconsole.sh gear P`, `scripts/vconsole.sh soc 40`.
- 녹화: 호스트에서 에뮬레이터 창 화면 녹화(macOS 화면 기록). `adb shell screenrecord`의 AAOS 동작은 미검증.
- 음성 안내가 영상에 들리도록 호스트 소리를 켠다 (TTS 엔진은 `TextToSpeech.getEngines()`로 실측 필요, ADR-0002).

## 주의

- 장면 5는 ADR-0003 규칙(주행 중 비교·펼치기·스크롤 불가)을 그대로 보여 준다.
- 에뮬레이터 Navi는 경로 시간·거리가 고정값에 가까워 장면 3의 도착 시간 변화는 실제 값이 아니다. 자막에 "시연 데이터"를 표시한다 (ADR-0001: 가상 데이터는 시연 한정).
- 경유지 추가 후 5–9초 재탐색 동안 목적지가 비어 보인다 (`docs/agents/emulator.md` §6). 장면 4는 `onWaypointChanged` 이후 상태로 촬영.
- 장면은 #14 통합 결과에 맞춰 조정한다. 구현되지 않은 흐름은 넣지 않는다.
