## 1. 앱 한 줄 소개

전기차 가족 여행에서 충전과 식사, 화장실, 아이 휴식을 한 번에 비교하고, 고른 정차 지점을 현재 경로의 경유지로 바로 추가하는 정차 도우미

## 2. 기획 배경

현재 전기차 EV6를 자가용으로 운행하고 있는데, 가족과 장거리 운전을 하면 어쩔 수 없이 중간에 휴게소 등을 들러 충전을 해야 합니다. 요즘은 대부분의 휴게소에 충전소와 편의시설이 갖춰져 있지만, 막상 운전하다 보면 어느 휴게소에서, 배터리가 얼마나 남았을 때 들어가야 충전과 식사를 가장 짧은 시간에 함께 끝낼 수 있을지 매번 고민하게 됩니다.

이 판단이 어려운 이유는 세 가지입니다. 첫째, 고속 충전기가 비어 있는지는 도착해 봐야 알 수 있습니다. 고속도로 휴게소 충전기 1,590기 중 약 43%가 100kW 이하이고(2025년 10월 기준), 2025년 추석 연휴에는 고속도로를 지난 전기차가 약 170만 대였습니다. 들어가 보니 고속 충전기가 모두 사용 중이거나 저속 충전기만 남아 있으면 충전 시간이 크게 늘고, 식사 계획도 함께 틀어집니다. 둘째, 고속 충전은 배터리 잔량이 낮을 때 빠르고 80%를 넘으면 느려지기 때문에, 어느 지점에서 충전하느냐에 따라 같은 거리를 가도 전체 이동 시간이 달라집니다. 셋째, 충전이 식사보다 먼저 끝나면 차를 옮기러 나가야 하고, 식사가 먼저 끝나면 차 앞에서 기다려야 합니다.

지금은 이 세 가지를 충전 앱, 지도 앱, 내비를 오가며 직접 맞춰 보고 있습니다. 운전 중에는 화면을 들여다볼 수 없고, 고속도로에서는 진입로를 지나치면 다음 휴게소까지 가야 해서 결정할 시간도 짧습니다. 그래서 차량의 실제 배터리 잔량과 주행 가능 거리를 바탕으로 정차 후보를 미리 비교하고, 주행 중에는 한 번 탭으로 경유지에 넣으며, 충전이 끝나는 시점에 맞춰 출발을 알려 주는 앱을 기획했습니다.

## 3. 앱 주요 기능 및 차량 특화 요소

| 기능 | 내용 | 차량 특화 |
|---|---|---|
| 이동 상황 판별 | AAOS `CarUxRestrictions`(주의분산 제한 여부)로 정차와 주행을 구분하고, 상태를 알 수 없으면 주행 중과 같은 제한 적용 | 주행과 정차 맥락 구분 |
| 주행 중 제한 | 상세 입력, 비교, 스크롤 차단. 큰 카드 최대 2개만 표시하고 한 번 탭으로 선택, 10초 안에 취소 가능 | 운전자 주의분산 최소화(`distractionOptimized`) |
| 여행 조건과 정차 필요 입력 | 목적지와 도착 희망 시간 지정, 식사와 화장실, 아이 휴식 중 필요한 항목 복수 선택. 계정 없이 시작하고 상세 입력은 정차 중에만 받으며, 주행이 시작되면 입력 중인 내용 보존 | 정차 중에만 입력 |
| 차량 에너지 확인 | Vehicle SDK로 EV 배터리 잔량, 충전 상태, 주행 가능 거리 수신. 값을 받지 못하면 수동 입력으로 대체하고 자동값과 구분해 표시 | 차량 데이터 활용 |
| 정차 후보 추천과 비교 | 후보 최대 3개를 가족 필요 충족 여부, 추천 이유, 도착 시간 변화, 이동 부담 순으로 비교. 데이터 출처(실제 또는 가상)와 확인 상태를 문구와 아이콘으로 표시 | 충전 정보와 경로 맥락 결합 |
| 길 안내 전달 | 선택한 지점을 `NaviHelper.addWaypoint`로 경유지에 추가하고 원래 목적지 유지. 경유지 2개가 이미 있으면 교체 대상 확인 | 내비 연동 |
| 충전 중 가족 활동 안내 | 정차 중 할 일 체크리스트와 차량에서 받은 충전 상태, 배터리 잔량 표시. 충전이 끝나면 차량 신호를 받아 출발 안내 | 전기차 충전 시간 활용 |
| 예외 대응 | 권한 거부나 데이터 미수신 시 안 되는 항목과 제한을 안내하고 수동 입력으로 대체. 마지막 확인값은 출처와 시각을 함께 표시 | 차량 환경의 불확실성 대응 |
| 음성 안내 | 결과를 1~2문장으로 안내하고, 주행 중에는 후보 최대 2개를 번호로 안내 | 핸즈프리 사용 |

## 4. 주요 사용 시나리오

전기차로 서울에서 장거리 가족 여행 중, 배터리 잔량이 줄고 있고 아이가 배고프다고 하는 상황

1. 휴게소에 정차하면 앱이 정차 상태를 인식해 상세 화면 표시, 목적지와 필요 항목(식사, 아이 휴식) 입력
2. 배터리 잔량과 입력을 바탕으로 정차 후보 최대 3개를 가족 필요 충족 여부 순으로 비교
3. 후보를 고르면 현재 경로에 경유지로 추가하고 원래 목적지는 유지
4. 이미 주행 중이면 상세 비교를 막고 큰 카드 2개만 표시. 한 번 탭으로 경유지에 반영하고 10초 안에 취소 가능, 결과는 음성으로 짧게 안내
5. 충전을 시작하면 정차 중 할 일(식사, 화장실, 아이 휴식) 체크리스트와 차량에서 받은 충전 상태, 배터리 잔량 표시. 충전이 끝나면 출발 안내
6. 권한 거부나 데이터 미수신 시 안 되는 기능을 알리고, 정차 후 수동 입력으로 이어서 진행

## 5. 개발 계획

**주요 개발 범위**

- 포함: 정차 조건 입력, 정차 후보 비교, 경유지 추가와 취소, 주행 중 제한 화면, 충전 중 가족 활동 안내, 예외 대응, 음성 안내
- 제외: 주유 전후 안내, 예약과 결제, 자체 지도와 길 안내, 수익화, 음성 입력(STT), 지표 수집(PT 이후 검토)
- 시설 데이터: Pleos SDK에 시설 검색 API가 없어 현재는 앱에 넣은 시연 구간 시설 데이터(실제와 가상 혼합)를 사용하고 화면에 출처 표시. 외부 시설 API는 공모전 규정을 운영사에 확인한 뒤 연결

**SDK와 API 사용 계획**

| SDK | 콘솔 상태 | 용도 | 계획 |
|---|---|---|---|
| Vehicle State | 사용 가능 | EV 배터리 잔량, 충전 상태, 주행 가능 거리 | 연동 완료. 주행 가능 거리는 `CAR_DRIVE` 권한 필요, 주행과 정차 판별은 기어 대신 AAOS `CarUxRestrictions` 사용 |
| NaviHelper | 사용 가능 | 정차 지점 경유지 추가와 취소, 경로 상태 조회 | 연동 완료, 에뮬레이터에서 동작 확인 |
| FusedLocation | 준비 중 | 현재 위치 | Android `LocationManager`로 대체, 공개 후 전환 |
| TextToSpeech | 준비 중 | 결과 음성 안내 | Android `TextToSpeech`로 대체, 공개 후 음성을 차량 밖으로 보내지 않는 Pleos `ON_DEVICE` 모드로 전환 |
| SpeechToText | 준비 중 | 음성 요청 | 시연에서 제외, 공개 후 검토 |

- 외부 API: 상시 무료 운영이 원칙이라 무료 한도를 넘을 수 있는 외부 API는 가상 데이터로 대체

## 6. 기대효과 및 발전 가능성

- **사용자 가치**: 충전 조건과 가족 필요를 한 번에 비교해 정차 계획에 드는 시간 단축, 주행 중에도 안전하게 경유지 반영
- **타깃**: 전기차로 가족 여행을 하는 운전자와 성인 동승자. 내연기관 차량은 후속 범위
- **예상 MAU와 Retention**
  - 근거 지표: 국내 전기차 누적 등록 약 109.5만 대, 이 중 국산 65.6%(국토교통부, 2026년 6월 말). Pleos Connect는 2026년 5월 신형 그랜저부터 탑재되며, 2030년까지 현대차, 기아, 제네시스 약 2,000만 대 탑재가 목표(현대차그룹 발표). 국내여행의 84.5%가 자동차 이용이고 1인당 연 6.5회 여행 중 1박 이상이 41.3%(2025 국민여행조사)
  - MAU 산정식: Pleos 탑재 전기차 수 × 설치율 × 월간 장거리 이동 확률. 월간 장거리 이동 확률은 1인당 연 약 2.7회(6.5회 × 41.3%)인 1박 이상 여행을 월 단위로 환산한 약 22% 적용
  - 산정 예시: 국내 Pleos 탑재 전기차 10만 대, 설치율 10%를 가정하면 MAU 약 2,200
  - Retention: 가족 장거리 여행이 주말과 연휴에 몰리는 특성상 월간 리텐션보다 분기 재사용률(같은 차량이 다음 장거리 여행에서 다시 사용하는 비율)을 핵심 지표로 사용. App Market 입점 후 첫 분기 실측값을 기준으로 목표 설정
- **확대 계획**: 공공데이터포털의 환경부 전기차 충전소 정보 API(충전기 상태)를 연결해 실시간 충전기 가용성과 출력 반영, 차량 배터리 잔량과 경로로 휴게소별 도착 시점 잔량을 계산해 충전 시간이 가장 짧은 정차 지점 추천, 내연기관 주유 전후 안내, STT 공개 후 음성 요청, 실제 시설 데이터 전환 후 앱 마켓 입점
